## Queue-wide definition of done

Each SPEC must cite the existing goso route/page/API it changes, include loading/empty/error/permission/stale states, define destructive confirmations and audit events, and prove that credential GET responses never contain secret values. UI work remains independently designed for goso; the benchmark supplies operator questions and state coverage, not implementation assets.
